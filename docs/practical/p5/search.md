# Локальный поиск и русские словоформы

Поиск MkDocs Material использует локальный индекс и языки `ru` и `en`.
Шрифты, поисковый worker и языковые скрипты поставляются вместе с сайтом.
Проверка выполняется в браузере на локальной сборке с запретом внешних origin.
Эта таблица исключена из индекса, чтобы запрос не находил сам себя.

В конфигурации явно включены `stemmer`, `stopWordFilter` и `trimmer`.
Material добавляет к запросу wildcard; стандартный Lunr для него пропускает
стемминг. Локальный `russian-search.js` применяет языковую pipeline к слову
перед восстановлением wildcard. Он загружает исходный worker установленной
темы; URL не закреплён вручную на хеш имени файла. Поведение pipeline описано
в [документации Material](https://squidfunk.github.io/mkdocs-material/plugins/search/#pipeline).

Проверка 4 октября 2026 года на локальной сборке, Chromium через Playwright:

| Запрос | Другая форма в тексте | Контрольная страница | Результат |
|---|---|---|---|
| измерениями | измерения | Результаты эксперимента | найдена |
| публикациями | публикация | Главная | найдена |
| угрозами | угроз | Модель угроз | найдена |
| ключами | ключ | Подключение Helios | найдена |
| ветками | ветки | Preview-сборки | найдена |

Все пять запросов вернули контрольные страницы, внешних запросов — ноль.
Сырой JSON сохраняется браузерной проверкой. Таблица относится к локальной
проверке, проверка этих URL на опубликованных хостингах ещё не проводилась.
Сохранён [результат проверки](../../evidence/logs/p5-local-browser.json)
двух срезов во временном репозитории: корень, `latest` и переход через
переключатель также проверены. Теги в рабочем репозитории при этом не создавались.

Повторить проверку после сборки можно так (Node.js 22):

```bash
npm ci --prefix tools/browser-check
tools/browser-check/node_modules/.bin/playwright install chromium
node tools/browser-check/check.cjs site site/search-check.json
```

На Windows с установленным Chrome можно указать `CHROME_PATH`, чтобы не
скачивать Chromium. Проверка умеет обходить корневые redirect и выбирать
другую версию через настоящий переключатель при передаче версионного artifact.
Стемминг не является словарём синонимов: произвольные родственные слова, например
«регрессия» и «регрессионный», не обязаны иметь одну основу.
