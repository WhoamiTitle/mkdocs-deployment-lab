# Публикация результатов исследований

Этот сайт является рабочим отчётом по заданиям **T4** и **P4** дисциплины
«Проектирование и развёртывание веб-решений в экосистеме Python».

В исследовательской части сравниваются риски пяти способов публикации
статического сайта. В практической части реализуется атомарное развёртывание на
Helios по SSH/rsync с preview-сборками, автоматической проверкой и откатом.

<span id="publication-site-control" hidden>publication-site-control</span>

## Проверяемые результаты

- воспроизводимая строгая сборка MkDocs;
- публикация на GitHub Pages;
- публикация production-версии на Helios;
- отдельный preview для каждой ветки;
- проверка HTTP-кода и идентификатора релиза;
- сохранение предыдущего релиза и откат;
- работа формул, шрифтов и иконок без внешних CDN;
- измерения времени развёртывания и размера сайта.

!!! note "Статус"
    Локальная сборка, тесты, preview, healthcheck и rollback проверены. GitHub
    Pages и Helios опубликованы; парная серия из трёх измерений, sandbox-проверки
    отказоустойчивости, очистка preview и работа без внешних CDN подтверждены
    фактическими результатами.
