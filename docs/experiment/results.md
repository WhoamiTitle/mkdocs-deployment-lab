# Результаты эксперимента

Исходные наблюдения хранятся в `evidence/measurements`, а на эту страницу
переносятся только вычисленные по ним сводные значения. Текущий срез содержит
пять локальных повторов и три из трёх запланированных наблюдений GitHub
Pages. Helios ещё не измерялся, потому что доступ к площадке не подключён.

## Локальная сборка

Серия выполнена 1 октября 2026 года на `darwin-arm64`, Python 3.13.7, commit
`3d28d598c8334f831973a0aca5f97d93b607823f`. Зависимости были установлены
заранее, каталог результата очищался перед каждой сборкой, системный файловый
кэш не сбрасывался.

| Операция | Запусков | Минимум, с | Медиана, с | Максимум, с | Успешно |
|---|---:|---:|---:|---:|---:|
| Strict build | 5 | 0,707 | 0,721 | 0,728 | 5/5 |
| Локальный deploy + healthcheck | 5 | 0,294 | 0,295 | 0,302 | 5/5 |

Артефакт содержал 131 файл и занимал от 4 509 378 до 4 509 379 байт. Разница
в один байт связана с изменяемыми метаданными релиза; набор исходных файлов и
commit SHA во всех пяти запусках совпадал, `dirty=false`.

| Площадка | Запусков | Минимум, с | Медиана, с | Максимум, с | Успешно |

| Helios | 0 | не измерялось | не измерялось | не измерялось | 0/0 |

Сырые наблюдения GitHub Pages: 66,806483; 78,507646; 53,725831 с. Все три

Значения включают push, очередь GitHub Actions, сборку, deploy и доступность
новой версии через публичный URL.

## Автономность опубликованного сайта

Для commit `0bd5d64` браузер с запретом внешних origin выполнил 16 запросов,
все к `whoamititle.github.io`. Формула KaTeX, локальные шрифты, SVG-иконки и
поиск по запросу «развёртывание» с четырьмя совпадениями работали. Переданный
объём страницы вместе с поиском составил 229 851 байт. Подробности и границы
метрики приведены в разделе [«Работа без внешних CDN»](../research/t4/cdn-independence.md).

## Выводы

1. В наблюдаемой серии официальный Pages artifact workflow доставлял новую
   версию за 53,726–78,508 с; медиана составила 66,806 с, успешность — 3/3.
2. Медиана локального strict build равна 0,721 с. Следовательно, основная часть
   пользовательской задержки GitHub Pages возникает после локально измеряемой
   генерации сайта. Это вывод по разнице масштабов, а не разложение времени на
   очередь, установку зависимостей, upload и CDN: длительности отдельных шагов
   в этой серии не собирались.
3. Self-hosting KaTeX добавляет в артефакт 1 378 961 байт, зато опубликованная
   страница не делает внешних runtime-запросов и сохраняет формулы, шрифты,
   иконки и поиск при блокировке других origin.
4. Для GitHub предпочтителен официальный Pages artifact: ему не требуется
   `contents: write`. Для Helios выбран SSH/rsync с отдельным ключом и атомарным
   переключением release-каталогов.
5. Сравнение GitHub Pages и Helios по времени, надёжности и откату пока не
   завершено. Нулевые или локально сымитированные значения вместо Helios в
   отчёт не подставляются.
