# P4. Развёртывание на Helios

Практическая часть реализует доставку статического сайта по SSH/rsync с
отдельным deploy-ключом.

Обязательные свойства решения:

- production публикуется из основной ветки;
- другие ветки получают собственный preview-каталог;
- новый релиз не изменяет текущий сайт во время загрузки;
- после публикации проверяются HTTP 200 и метка коммита;
- предыдущий релиз сохраняется для отката;
- секреты отсутствуют в исходном коде и журналах.

Локальный файловый адаптер воспроизводит ту же модель релизов без доступа к
Helios. Это позволяет проверить сценарии до подключения внешней площадки.
