# Работа без внешних CDN

Сайт должен сохранять читаемое оформление, формулы и иконки при недоступности
внешних сетевых ресурсов.

## Принятое решение

- системные шрифты вместо Google Fonts;
- KaTeX и его шрифты хранятся в `docs/assets/vendor/katex`;
- иконки темы Material поставляются вместе с установленной темой;
- пользовательские JavaScript и CSS находятся в `docs/assets`.

## Метод проверки

1. Собрать сайт локально.
2. Открыть страницу через локальный HTTP-сервер.
3. Заблокировать запросы к адресам, отличным от origin сайта.
4. Проверить формулу, шрифты, иконки и поиск.
5. Зафиксировать число запросов и переданный объём.

## Локальная контрольная проверка

28 сентября 2026 года команда `offline-check` просканировала 18 HTML-файлов и
4 CSS-файла; внешних runtime-ресурсов не обнаружено. В браузере найдено три
отрендеренных узла KaTeX, необходимые `.woff2`-шрифты были запрошены с того же
локального origin. Поиск по запросу «развёртывание» вернул две страницы.

Эта проверка подтверждает локальную сборку. Итоговая таблица будет дополнена
измерением опубликованных версий GitHub Pages и Helios.
