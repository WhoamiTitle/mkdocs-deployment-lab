# Контракт развёртывания

## Входные данные

| Значение | Назначение | Ограничение |
|---|---|---|
| `commit_sha` | версия исходного кода | непустая строка |
| `branch` | источник публикации | преобразуется в безопасный slug |
| `site_dir` | собранный артефакт | должен содержать `index.html` и `release.json` |
| `deployment_root` | закрытое хранилище релизов | относительный путь внутри домашнего каталога |
| `public_path` | публичная ссылка | относительный путь внутри домашнего каталога |

## Переменные внешней среды

| Имя | Тип | Секрет |
|---|---|---|
| `HELIOS_HOST` | variable | нет |
| `HELIOS_USER` | variable | нет |
| `HELIOS_PORT` | variable | нет |
| `HELIOS_DEPLOYMENT_ROOT` | variable | нет |
| `HELIOS_PUBLIC_PATH` | variable | нет |
| `HELIOS_BASE_URL` | variable | нет |
| `HELIOS_SSH_KEY` | secret | да |
| `HELIOS_KNOWN_HOSTS` | secret или защищённая variable | содержит доверенный ключ хоста |

## Ошибки

- отсутствие обязательных файлов останавливает публикацию;
- небезопасный удалённый путь отклоняется до запуска SSH;
- неуспешный `rsync` не переключает публичную ссылку;
- ошибка production healthcheck инициирует откат;
- секретные значения не включаются в сообщения об ошибках.
