# P5: версии опубликованного сайта

Практическая часть реализует версионирование опубликованного сайта
с помощью `mike` на GitHub Pages и Helios.

Обязательные свойства решения:

- опубликованы стабильные версии `v1.0` и `v1.1`;
- версия создаётся из git-тега;
- доступны переключатель версий и стабильный алиас `latest`;
- обычные push обновляют preview ветки;
- локальный поиск поддерживает русский язык и проверен на пяти словоформах.

Подробности выполнения:

- [Публикация стабильных версий](publication.md): содержание срезов, теги и правила публикации.
- [Переключение версий и алиас latest](latest.md): выбор версии и изменение алиаса.
- [Адреса и структура каталогов](layout.md): публичные пути, хранение состояния и очистка preview.
- [Откат опубликованных версий](rollback.md): восстановление предыдущего набора на Pages и Helios.
- [Локальный поиск](search.md): настройка и результаты проверки пяти запросов.
