# Healthcheck

После сборки в `index.html` добавляется meta-тег:

```html
<meta name="deployment-commit" content="<commit-sha>">
```

Проверка считается успешной при одновременном выполнении условий:

1. сервер вернул HTTP 200;
2. HTML содержит уникальную метку ожидаемого релиза и коммита;
3. HTML содержит постоянную контрольную строку проекта.

Проверка конкретного хеша защищает от ситуации, когда URL доступен, но сервер
продолжает возвращать предыдущую или закэшированную версию.
