# Переключение версий и алиас latest

Корень сайта перенаправляет на `latest/`, а алиас — на выбранную стабильную
версию. Переключатель использует список версий и алиасов из `versions.json`.
Прямые ссылки `v1.0/` и `v1.1/` позволяют открыть нужную версию независимо
от текущего значения `latest`.

Select latest version с параметром `version=v1.0` меняет алиас на всех целях.
Эта операция не создаёт версию и не пересобирает страницы. Обычный push меняет
только preview; следующая публикация стабильного тега снова выбирает максимум.

Изменение алиаса отличается от [отката всего опубликованного набора](rollback.md).
